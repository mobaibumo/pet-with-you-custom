# Codex 额度卡片本地预览

这份改动已于 2026-10-24 经用户审核后同步到本机日常安装；保留 1.0.2 原版本号，作为本地定制，不冒充上游正式发布。

卡片使用现有额度结构，不解析中文显示字符串。查询数据、权限和模型调用流程不变；剩余进度由已用比例换算，空值显示“未提供”，0 次重置显示“0 次”。卡片采用 60% 整体缩放，最大呈现宽约 216 CSS px（内部排版宽 360 px），按实际屏幕与透明窗口交集收窄，跟随现有 Windows 页面缩放，角色尺寸不再直接决定卡片字号；窄卡片使用容器尺寸调整标题和数字。正常两周期内容无需滚动；高度不足时内容区滚动，关闭按钮留在固定标题区。已验证 240/280/320 px 可用宽度及 280 px 可用高度。

只有头像、水波为透明 PNG，其余文本、进度条和卡片使用原生 DOM/CSS。图片是本次用内置 Image Gen 生成的装饰资产，基于原角色参考，素材归属与上游非商业边界保持不变。生成提示词摘要：制作透明横向 UI 标题装饰，左侧蓝发鲸鱼女仆头像，右侧浅蓝水波与小鲸鱼，禁止任何文字、按钮、卡片背景，保持中间标题区域可覆盖实时文字。
